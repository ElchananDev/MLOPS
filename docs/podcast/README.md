# מאפס למומחה · הפודקאסט

גרסת השמע של המדריך. שמונה פרקים, כ-41 דקות.

## איך מאזינים

פתח את [`index.html`](index.html) בדפדפן. זהו.

הנגן מקריא במנוע הדיבור שכבר קיים במכשיר — אין מה להתקין ואין צורך בחשבון.
אם לא נמצא קול עברי, הדף אומר לך בדיוק איך להוסיף אותו במערכת ההפעלה.

מה יש בנגן:

- שמונה פרקים, מחולקים ל-113 מקטעים
- לחיצה על כל פסקה מתחילה את ההקראה ממנה
- בחירת קול ומהירות דיבור (0.6 עד 1.6)
- המשך אוטומטי לפרק הבא
- התקדמות נשמרת בדפדפן, כך שאפשר לחזור באמצע
- תמלול מלא על המסך, גם בלי הקראה
- מקשים: רווח מנגן ועוצר, חצים מדלגים בין מקטעים

## הקבצים

| קובץ | מה זה |
| --- | --- |
| `index.html` | הנגן. קובץ עצמאי אחד, עם הגופנים והתסריט בפנים |
| `script.md` | התסריט המלא לקריאה |
| `script.json` | אותו תסריט במבנה מובנה — המקור להפקה |
| `pronounce.json` | מילון הגייה: 87 מונחים באנגלית ואיך להגות אותם בעברית |
| `make_audio.py` | הפקת קובצי שמע דרך Google Cloud Text-to-Speech |

## למה צריך מילון הגייה

קול עברי שמנסה לקרוא `MLOps` או `Pipeline` באותיות לטיניות נשמע רע.
לכן לפני ההקראה בלבד, המונחים מוחלפים בכתיב עברי — `אם-אל-אופס`, `פייפליין`.
הטקסט שעל המסך נשאר במקור.

המילון מופיע גם בתוך `index.html` (כמערך `SAY`) וגם ב-`pronounce.json`.
אם אתה מוסיף מונח, עדכן את שניהם.

## הפקת קובצי אודיו אמיתיים

הנגן מספיק לרוב השימושים. אם אתה רוצה קובצי MP3 להורדה, להפצה, או להעלאה
לשירות אירוח כמו SoundCloud, יש `make_audio.py`:

```bash
python3 make_audio.py --dry-run          # היקף ועלות, בלי מפתח ובלי קריאה ל-API
export GOOGLE_TTS_API_KEY="..."
python3 make_audio.py --list-voices      # אילו קולות עבריים זמינים בחשבון שלך
python3 make_audio.py --voice he-IL-Wavenet-D
```

התוצאה היא קובץ לכל פרק ב-`audio/`, ואם מותקן `lame` או `ffmpeg` — גם MP3.

היקף ההפקה המלאה: 113 בקשות, 32,156 תווים. בדוק את התמחור והמכסה הנוכחיים
של Google לפני שאתה מריץ, במיוחד אם אתה מתכוון להפיק שוב ושוב.

> `--dry-run` ו-`--list-voices` נבדקו. מסלול ההפקה עצמו לא הורץ מקצה לקצה,
> כי אין כאן מפתח API.

## עריכת התסריט

`script.json` הוא המקור. כל פרק הוא אובייקט עם `n`, `title`, `chapters`
ורשימת `segments`, וכל מקטע הוא זוג של סוג וטקסט. הסוגים:
`intro`, `talk`, `key`, `warn`, `task`, `outro`.

אחרי עריכה יש להטמיע מחדש את ה-JSON בתוך `index.html` (הוא יושב שם
בתוך `<script id="podcastData">`), ולהפיק מחדש את `script.md`.
