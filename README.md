## הרצת המעבדה

```bash
cd labs/iris-service
python -m venv .venv && source .venv/bin/activate
python -m pip install -r requirements-dev.txt

python train.py        # אימון ויצירת artifacts/
python -m pytest -q    # 7 בדיקות
make serve             # שירות על http://127.0.0.1:8000/docs
```

## הערות

- הדוגמאות המספריות במדריך הן לימודיות. אין להסיק מהן ביצועים של מערכת אמיתית.
- דף ה־HTML הוא קובץ עצמאי: הגופנים מוטמעים בתוכו, ואין בו תלות ברשת.
- כדי לבנות מחדש את ה־PDF, פתח את `docs/index.html` בדפדפן והדפס ל־PDF בגודל A4.
